# Task Management App


## Project Overview

This project demonstrates the use of **DOM** and **BOM** properties, methods, and techniques to create a dynamic web application. It incorporates **event-driven programming** and **basic form validation** using both built-in HTML attributes and JavaScript.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)


## Features

- **DOM Manipulation**: Utilizes DOM properties and methods to dynamically update the UI.
- **BOM Techniques**: Implements BOM functionalities such as working with `window` and `navigator` objects.
- **Event-Driven Programming**: Responds to user interactions with event listeners and handlers.
- **Form Validation**: Includes client-side validation using both HTML attributes and JavaScript.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
